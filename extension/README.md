# 跨境电商工具箱 / Cross-border Trade Toolkit

Chrome（Manifest V3）插件，面向跨境电商 / 外贸人员，中英双语，国内外网络均可使用，无需注册、无需 API Key、不收集任何数据。

## 功能 Features

| 工具 | 说明 |
| --- | --- |
| 体积重计算 | 长×宽×高÷系数；预设 5000 / 6000 / 4000 / 8000 / 海运 1000 / 美制 139、166；支持 cm·kg 与 in·lb、件数、实际重量对比、0.5 进位 |
| 单位换算 | 长度、重量、体积、面积、温度；公制 / 英制 / 市制，点击结果复制 |
| 时区查询 | 实时世界时钟（自动处理夏令时）、可自定义主时区和城市、上班时间提示、任意时间换算 |
| 国家/地区二字码 | 250 个国家/地区：二字码、三字码、电话区号、与主时区的实时时差；名称随界面语言显示 |
| 美国关税查询 | 通过美国国际贸易委员会 (USITC) HTS 官方接口查基础税率与 301 条款；叠加 2026-07-24 起的新 Section 301 税率；货值估算 |
| 欧盟关税查询 | 一键带参数跳转 TARIC / Access2Markets；内置到岸成本估算（关税 + 进口增值税，含 €150 以下 €3 固定关税） |
| 邮编查地址 | 80+ 国家精确邮编库（Zippopotam.us），其余国家自动回退 OpenStreetMap Nominatim |
| 汇率换算 | 160+ 币种实时汇率（open.er-api.com，失败自动切换 jsDelivr currency-api、Frankfurter），本地缓存 6 小时，可设点差/手续费，常用币种可增删 |
| HS 编码查询 | 中英文品名或编码：内置 300+ 常见跨境商品的 HS6 参考库（离线可用）+ 美国 HTS 在线检索（USITC）；97 章目录；一键跳转美国关税 / 欧盟 TARIC |
| 图片压缩 / 平台尺寸 | 两种模式：①平台预设（亚马逊、沃尔玛、eBay、Temu、速卖通、Shopee、TikTok Shop、Lazada、Shopify，可自定义），一张图同时输出多个平台的精确尺寸与体积上限；②仅压缩（视觉无损，默认 ≤2MB）。批量、拖拽、Ctrl+V 粘贴、ZIP 分平台文件夹下载。全程本机处理不上传 |

右下角 ↗ 可在独立标签页中打开（更大的界面）。左下角切换界面语言（自动 / 中文 / English）。

### 图片压缩的工作方式

1. 已经在目标大小内的图片：原样保留，不做任何处理。
2. 否则保持原始像素尺寸，在「画质下限」（默认 0.85）到 0.95 之间二分查找，取不超过目标大小的最高画质。
3. 画质到下限仍超出：允许时轻微缩小尺寸（最长边不低于 800px），再把省下的体积换回画质。
4. 极端情况（例如超大的高噪点图且关闭了缩小尺寸）：才会低于画质下限，并在结果里明确标出。
5. 透明 PNG：自动输出 WebP 以保留透明；选 JPG 则透明背景填白。输出会去掉 EXIF（含拍摄位置）。
6. 严格的「零画质损失 + 保证不超过某个大小」在数学上无法对所有图片成立，这里的目标是「肉眼看不出差别 + 一定不超过」。

### 平台尺寸预设与批量

- 内置 13 个预设（见 `js/data/imgpresets.js`），每个预设含输出尺寸、体积上限和说明。**这些是根据平台公开说明和卖家社区整理的参考值（2026-10），平台规则会调整，请以卖家后台为准**；可在界面里添加自定义预设（名称、宽、高、体积上限，保存在本机）。
- 输出是**精确的目标像素尺寸**：「补边」保留完整商品并用白色 / 自定义色 / 图片四角底色补足；「居中裁切」填满画面。原图较小可选择放大，并会提示「原图低于平台建议的最小尺寸」。
- 「自动裁掉多余空白边，让商品占画面 N%」（默认 85%，对应亚马逊主图要求）：检测与四角底色不同的区域并居中放大。适用于白底 / 纯色底图；复杂背景的图片检测不到边界时保持原样。
- 预设模式下尺寸固定，只在体积上限内搜索最高画质（不低于「画质下限」；实在压不下去时才会低于并明确标出）。可设「统一限制」，与各平台上限取较小值。
- 批量：一次选多张图 × 勾选多个预设 = 全部输出；ZIP 内按 `平台_宽x高/` 分文件夹；文件名模板支持 `{name}` `{n}` `{preset}` `{size}`（如亚马逊 `B0XXXXXXXX.PT{n}`）；改了设置后可「按当前设置重新处理」。

> 在工具栏弹窗里选择文件时，部分系统会让浏览器关掉弹窗，建议点左下角 ↗ 在新标签页使用。

## 安装 Install

1. 解压 zip（或直接使用 `cbt-toolkit` 文件夹）。
2. Chrome 打开 `chrome://extensions`，右上角开启「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的文件夹（包含 `manifest.json` 的那一层）。
4. 点击工具栏拼图图标，把「跨境电商工具箱」固定到工具栏。

Edge / Brave 等 Chromium 浏览器同样适用。

## 权限说明 Permissions

- `storage`：保存语言、时区列表、上次使用的工具。
- `clipboardWrite`：点击结果复制。
- 网络访问仅限以下站点：`hts.usitc.gov`（美国关税、HS 在线检索）、`api.zippopotam.us` 与 `nominatim.openstreetmap.org`（邮编）、`open.er-api.com` / `cdn.jsdelivr.net` / `api.frankfurter.dev`（汇率，依次备用）。不使用任何统计或广告脚本；图片只在本机处理。
- 从旧版升级到 1.2.0 时，Chrome 会因为新增了站点权限而要求重新确认一次。

## 需要定期维护的数据 Data to keep up to date

政策类数据集中在 `js/data/rules.js`：

- `US_RULES`：新 Section 301（强迫劳动）税率分档，更新日期 2026-07-24。其中 10% 档、欧盟/台湾（MFN+301 合计 ≤10%）、日韩瑞士（≤12.5%）来自 Morgan Lewis 2026-07-27 的公告解读；中国、越南、泰国 12.5% 来自公开税率追踪。其他被调查经济体也是 12.5%，但完整名单未内置——这些国家会提示「不在内置名单」，可在界面里手动填写加征税率。
- `EU_VAT`：欧盟 27 国标准增值税率（2026 年中，仅供参考）。
- `EU_LOW_VALUE`：欧盟 €150 以下 B2C 包裹 €3 固定关税（2026-07-01 起的过渡措施）。

- `js/data/imgpresets.js`：各平台图片尺寸 / 体积预设（参考值，更新日期 `IMG_PRESETS_ASOF`）。
- `js/data/hsdata.js`：97 章目录与常见品类 HS6 参考库（HS 2022 子目；各国 8–10 位细分不同，归类以海关认定为准）。

汇率为国际市场中间价，仅供参考；实际结算以银行 / 支付平台汇率为准。open.er-api.com 要求注明出处，界面会在使用该数据源时显示。

关税与法规变化很快，所有结果仅供参考，不构成报关或法律意见，请以海关/官方公告为准。
